# 🎵 MusicSage Bot — Telegram Music Assistant with Source Separation

> *Телеграм-бот, который понимает музыку, разделяет треки на инструменты и помогает музыкантам разбирать песни.*

---

## ✨ О проекте

Будучи музыкантом, я часто сталкиваюсь с задачей: как разобрать сложную партию баса или барабанов, когда всё играет одновременно. Слушая готовый трек — трудно, но если услышать инструмент отдельно — становится очевидно.

**MusicSage** решает эту проблему.  
Бот принимает аудиофайл и разделяет его на 4 чистых канала:

- 🥁 Барабаны  
- 🎸 Бас  
- 🎤 Вокал  
- 🎹 Остальное (остальные инструменты)

Параллельно бот поддерживает разговор о музыке — как дружелюбный собеседник, который помогает разбирать треки, советует литературу или обсуждает теорию музыки.

---

## 🎯 Цели проекта

### Основная задача
Разделение музыкального аудио на инструментальные каналы (Source Separation) с помощью нейросетевой архитектуры.

### Второстепенные задачи
- Реализовать полноценного Telegram‑бота с диалоговым агентом на тему музыки
- *(Планируется)* Подключить API для поиска текстов песен по названию и исполнителю

---

### Решение для меня сейчас выглядит так:
подход к разработке основного модуля по разделению аудио на данный момент для меня выглядит как применение encoder / decoder U-net (т.к идет преобразование одной последовательности в другую)
начать можно с CNN и сырого аудио сигнала, дальнейшими шагами можно рассматривать переход на rnn, использование блока внимания, а так же использование спектрограмм

---

## 🤖 Агент и диалог

Бот не просто разделяет аудио, но и **говорит о музыке**:

- Роль агента задаётся через промпт (без RAG / без хранения документов)
- Локальная LLM (запускается на ноутбуке) — никаких внешних API для общения
- Бот поддерживает беседу о теории музыки, инструментах, анализе треков

---

## 🗃️ Данные для обучения

База данных: **[MUSDB18](https://sigsep.github.io/datasets/musdb.html)**  
— стандарт для задач source separation. Содержит полные треки + изолированные дорожки (бас, барабаны, вокал, остальное).

---

## 🛠️ Стек технологий

| Компонент       | Технологии |
|----------------|------------|
| Глубокое обучение | TensorFlow, Keras |
| Архитектура    | U‑Net + CNN → далее RNN / Attention |
| Локальная LLM  | LLaMA (локально, на ноутбуке) |
| Оркестрация агента | LangChain |
| Интерфейс      | Telegram Bot API |
| Данные         | MUSDB18 |

---

## 📦 Ожидаемый результат

- Telegram‑бот, который:
  1. Принимает аудиофайл от пользователя
  2. Возвращает 4 разделённых трека (drums, bass, vocals, other)
  3. Поддерживает разговор о музыке и помогает разбирать композиции

- Модуль source separation:
  - сначала на CNN + сырой сигнал
  - затем улучшенный с вниманием и спектрограммами

- *(Доп. цель)* Поиск текста песен по запросу `название + исполнитель`

## 🧑‍🎤 Почему именно эта тема?

1. **Личная страсть** — я люблю музыку, писать её, анализировать и постоянно искать новое.  
2. **Инженерный вызов** — это не «очередной ToDo‑бот», а задача на стыке DSP, глубокого обучения и UX.  
3. **Практическая ценность** — такой инструмент помог бы тысячам музыкантов быстрее разбирать песни.
